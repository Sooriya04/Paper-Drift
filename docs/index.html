$ npx paper-drift paper.pdf --format image
• Renders pages in < 250ms • Direct Base64 data URI output • 100% private local execution

02 // ARCHITECTURE

High-Precision Rasterization Pipeline

Compiled C libraries execute inside the V8 WebAssembly virtual machine, rendering vector PDF pages directly to raster pixel buffers.

STEP 01

Binary Ingestion

Accepts raw file paths, Node.js Buffers, or Uint8Array binary streams. Zero temporary disk writes required.

STEP 02

Matrix Scaling

Applies high-DPI affine transformations (144 DPI Retina, 216 DPI ultra-res) for pixel-crisp typography and figures.

STEP 03

Base64 & Buffer Output

Outputs PNG binary buffers alongside complete data:image/png;base64,... data URIs ready for web, storage, or APIs.

03 // QUICKSTART

Developer Integration

Run immediately via terminal with npx or import directly into your JavaScript / TypeScript codebase.

bash 
# 1. Convert all pages to high-res PNG images
npx paper-drift paper.pdf --format image

# 2. Extract page 1 as a PNG image
npx paper-drift paper.pdf output.png --pages 1

# 3. Export all pages into an images/ folder
npx paper-drift paper.pdf images/ --pages 1-3

# 4. Export Base64 JSON containing data URLs
npx paper-drift paper.pdf output.json --format base64

# 5. Render transparent PNG (no white background)
npx paper-drift diagram.pdf diagram.png --no-bg
import { convertPdfToImages } from 'paper-drift';
import fs from 'node:fs';

const result = await convertPdfToImages('research-paper.pdf', {
  scale: 2.0,       // 2x Retina (144 DPI)
  pages: '1-3',     // Target page range
  transparent: false
});

console.log(`Rendered ${result.pagesProcessed} pages in ${result.durationMs}ms`);

for (const page of result.pages) {
  // Binary buffer for file writing
  fs.writeFileSync(`page-${page.pageNumber}.png`, page.buffer);

  // Complete Base64 data URL: "data:image/png;base64,..."
  console.log(page.dataUrl);
}
import { convertPdfToImages } from 'paper-drift';

const { pages } = await convertPdfToImages('document.pdf', { pages: 1 });
const pageOne = pages[0];

// 1. Raw Base64 string
console.log(pageOne.base64);

// 2. Embed directly in HTML img tag
const imgTag = `<img src="${pageOne.dataUrl}" width="${pageOne.width}" />`;

// 3. Pass to API payloads
const payload = {
  mimeType: 'image/png',
  base64: pageOne.base64
};
04 // API REFERENCE

Options & Parameters

Programmatic options supported by convertPdfToImages(input, options):

Option Type Default Description
scale number 2.0 Resolution scale factor (2.0 = 144 DPI, 3.0 = 216 DPI)
pages string | number | number[] "all" Page range specification (e.g. "1-5", "2,4", 1)
transparent boolean false Render with transparent background instead of opaque white
onProgress function undefined Callback invoked as each page is rasterized
