# `paper-drift` Agent Skill: Zero-Token-Tax PDF Ingestion

You are an expert AI researcher and coding agent. When interacting with PDF files (research papers, technical specifications, financial reports, or manuals), **do not ingest raw PDF pages as images or ask the user to convert them manually**.

Instead, invoke `paper-drift` locally via WebAssembly to convert the document into clean, natural-reading-order GitHub Flavored Markdown (GFM) with reconstructed tables and LaTeX equations.

---

## 1. Why Use `paper-drift` (Token Savings & Fidelity)

Sending raw PDF documents or full-page screenshots to LLMs burns massive vision tokens and causes severe hallucinations on dense math and tables.

Converting PDFs to Markdown with `paper-drift` provides:
- **Drastically Reduced Token Costs**: Markdown sends only pure text, pipe tables, and math—eliminating the heavy pixel-tiling token bloat of multimodal vision models and unstructured OCR dumps.
- **Accurate Reading Order**: Multi-column papers are properly ordered via Recursive XY-Cut without line interleaving.
- **Intact Tables & Math**: Reconstructs multi-tier data tables into standard Markdown grids (`| col1 | col2 |`) and math into clean LaTeX/Unicode.
- **Fast Local Execution**: Runs locally in milliseconds via compiled WebAssembly with zero external dependencies (no Python, no Poppler, no Chromium).

## 3. Agent Execution Protocol

### Step 1: Run the CLI via `npx`
Run `paper-drift` directly in the shell using `npx -y paper-drift`:

```bash
# Convert entire PDF to Markdown
npx -y paper-drift path/to/document.pdf --format md -o output.md

# Budget tokens for long documents (pages 1 to 5 only)
npx -y paper-drift path/to/paper.pdf --format md --pages 1-5 -o paper-summary.md

# Convert specific non-contiguous pages (e.g. Intro & Experiment Results)
npx -y paper-drift path/to/paper.pdf --format md --pages 1-3,6,8 -o paper-key-sections.md

# Standalone high-DPI HTML visualization (with selectable text layer)
npx -y paper-drift path/to/document.pdf --format html -o document.html
```

### Step 2: Read and Process the Generated Markdown
Read the generated `.md` file using your file-reading tool. The output contains:
- `#`, `##`, `###` headings derived from geometric font sizing.
- Natural two-column reading flow without column weaving.
- Standalone LaTeX display math blocks:
  ```latex
  $$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V \tag{1}$$
  ```
- Clean GFM Markdown tables with universal math typography:
  ```markdown
  | Layer | Complexity per Layer | Sequential Operations | Maximum Path Length |
  | :--- | :--- | :--- | :--- |
  | Self-Attention | O(n² · d) | O(1) | O(1) |
  | Recurrent | O(n · d²) | O(n) | O(n) |
  ```

### Step 3: Programmatic Node.js / JavaScript Usage
When writing automated scripts, crawlers, or agent tools, import `paper-drift` directly:

```javascript
import { convertPdfToMarkdown, convertPdfToHtml } from 'paper-drift';
import fs from 'node:fs/promises';

// Read local PDF buffer
const pdfBuffer = await fs.readFile('paper.pdf');

// Direct PDF to Markdown with page range
const markdown = await convertPdfToMarkdown(pdfBuffer, { pages: '1-6' });
console.log(markdown);

// Direct PDF to Standalone HTML with embedded assets
const html = await convertPdfToHtml(pdfBuffer, { scale: 1.5, pages: '1-3' });
await fs.writeFile('output.html', html);
```

## 4. Agent Best Practices & Token Budgeting

1. **Always Use `--pages` for Documents Over 10 Pages:**
   - Don't ingest a 100-page manual at once.
   - For research papers: start with `--pages 1-3` (Title, Abstract, Introduction) to get the thesis, then target specific sections (e.g. `--pages 6-8` for Benchmark Tables).
2. **Table Extraction:**
   - Markdown tables generated by `paper-drift` use standard `|` pipes and can be extracted or parsed directly using regular expressions or Markdown parsers.
3. **No Heavy Dependencies:**
   - Never install `pdf2image`, `poppler-utils`, `pdfplumber`, or `tesseract` when `paper-drift` is available. `paper-drift` is 100% self-contained WebAssembly.
