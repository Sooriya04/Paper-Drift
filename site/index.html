03 // ARCHITECTURE

Deterministic Four-Stage Pipeline

Documents move straight from binary buffers through layout analysis to structured outputs without temporary disk writes.

01 / INGESTION

Zero-Copy Buffer Loading

Reads file paths, Node.js Buffers, or Uint8Array streams directly into the WebAssembly linear memory space.

02 / SPATIAL ENGINE

XY-Cut & Vector Analysis

Recursive XY-Cut resolves multi-column reading order while vector rule heuristics extract Booktabs grids and LaTeX math.

03 / COMPILATION

Multi-Format Emission

Generates GFM Markdown, citation-grounded RAG chunks, structured Document IR JSON, and high-DPI PNG / Base64 buffers.

04 / DAEMON

Persistent Microservice

Exposes paper-drift serve --port 7490 with /api/health monitoring and bounded concurrent request guards.

04 // QUICKSTART

CLI & SDK Integration

Run immediately with npx or import the zero-dependency TypeScript/ESM SDK into your application.

bash 
# 1. Semantic RAG chunks (preserves tables & math formulas)
npx paper-drift paper.pdf --format chunks --max-chunk-chars 1500 -o chunks.json

# 2. Publication Markdown with vector tables & LaTeX math
npx paper-drift paper.pdf paper.md

# 3. Convert all pages to high-res PNG images
npx paper-drift paper.pdf --format image

# 4. Extract page 1 as a PNG image
npx paper-drift paper.pdf output.png --pages 1

# 5. Export Base64 JSON containing data URLs
npx paper-drift paper.pdf output.json --format base64
import { chunkPdfForRag } from 'paper-drift';

const chunks = await chunkPdfForRag('research-paper.pdf', {
  max_chunk_chars: 1500,  // Target character limit per chunk
  pages: '1-10'           // Page scope
});

console.log(`Generated ${chunks.length} atomic semantic chunks`);

for (const chunk of chunks) {
  // Grounded page citation & atomic math/table integrity
  console.log(`[${chunk.chunk_id}] ${chunk.section} (Page ${chunk.page})`);
  console.log(`Has Table: ${chunk.has_table} | Has Math: ${chunk.has_math}`);
  console.log(chunk.content);
}
import { convertPdfToMarkdown } from 'paper-drift';
import fs from 'node:fs';

const result = await convertPdfToMarkdown('attention.pdf', {
  pages: 'all',
  tables: true,           // Reconstruct GFM tables
  extractImages: true     // Crop embedded figures
});

console.log(`Converted in ${result.durationMs}ms`);
fs.writeFileSync('paper.md', result.markdown);
import { convertPdfToImages } from 'paper-drift';

const { pages } = await convertPdfToImages('document.pdf', { pages: 1 });
const pageOne = pages[0];

// 1. Raw Base64 string
console.log(pageOne.base64);

// 2. Embed directly in HTML img tag
const imgTag = `<img src="${pageOne.dataUrl}" width="${pageOne.width}" />`;

// 3. Pass to API payloads
const payload = {
  mimeType: 'image/png',
  base64: pageOne.base64
};
# 1. Start daemon on default port 7490
npx paper-drift serve

# 2. Or start on custom port
npx paper-drift serve --port 8080

# 3. Query health check
curl http://localhost:7490/api/health
# Returns: {"status":"ok","uptime":42,"version":"0.1.6","activeRequests":0,"maxConcurrent":4}

# 4. Parse document bundle via POST
curl -X POST "http://localhost:7490/api/parse-full?pages=1-2" \
  -H "Content-Type: application/pdf" \
  --data-binary "@paper.pdf"
05 // API REFERENCE

Core SDK & Server Exports

Typed ESM functions exported by paper-drift:

Function Primary Options Output Description
chunkPdfForRag(input, opts) max_chunk_chars, pages Promise<RagChunk[]> Semantic RAG chunking with atomic math ($...$) and GFM tables preserved.
convertPdfToMarkdown(input, opts) pages, tables, extractImages Promise<MarkdownResult> Publication GFM Markdown with LaTeX math, Booktabs, and section anchors.
parsePdfBundle(input, opts) pages, scale, includeImages Promise<UnifiedBundle> Consolidated JSON: metadata, markdown, reader images, and RAG sections.
convertPdfToImages(input, opts) scale, pages, transparent Promise<ImagesResult> High-resolution PNG buffers and Base64 data URIs.
startServer(port) port (default: 7490) Promise<http.Server> Spawns the HTTP microservice daemon with /api/health and REST endpoints.
