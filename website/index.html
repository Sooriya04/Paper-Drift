02 // ARCHITECTURE

Core Engine Specifications

No Python microservices. No headless Chromium containers. Pure geometric layout analysis executed in compiled WebAssembly.

SPEC 01 Spatial Order

Recursive XY-Cut

Dynamically detects column gutters and full-width banners. Decomposes 2-column and 3-column academic papers into natural reading order without interweaving columns horizontally.

SPEC 02 Tabular Grids

Geometric Table Reconstruction

Discovers vertical column gutters across dense data rows and slices cells into standard GFM pipe tables (| col1 | col2 |) with folded multi-tier headers and zero hardcoding.

SPEC 03 Math Typography

Universal Math & LaTeX

Converts table math to clean universal Unicode superscripts (O(n² · d), 2.3 · 10¹⁹) readable in any viewer, and frames display formulas in LaTeX $$...$$ blocks.

SPEC 04 Runtime

18.9 KB Zero-Dep Core

No Puppeteer, no Python, no Docker. Compiled WebAssembly executes instantaneously across Node.js, Bun, and browser runtimes with under 20 KB package footprint.

03 // INTEGRATION

Developer Quickstart

Run as a standalone CLI tool, import as an ESM module, or hook directly into an autonomous AI agent harness.

bash 
# 1. Convert directly to clean Markdown
npx paper-drift research-paper.pdf output.md --format md

# 2. Convert specific pages to Markdown
npx paper-drift attention.pdf output.md --format md --pages 1-5,8

# 3. Convert to pixel-perfect standalone HTML
npx paper-drift attention.pdf output.html --scale 2.0
import { convertPdfToMarkdown, convertPdfToHtml } from 'paper-drift';

// Ingest PDF to Markdown (tables, headings, LaTeX math)
const { markdown, pages } = await convertPdfToMarkdown('paper.pdf', {
  pageRange: '1-10'
});

console.log(markdown);

// Ingest PDF to standalone high-DPI HTML
const { html } = await convertPdfToHtml('paper.pdf', { scale: 2.0 });
// In your AI Agent tool handler (Cursor, Claude Desktop, Antigravity):
async function handleReadPdfTool({ filePath }) {
  // Ingests locally via WebAssembly in < 50ms
  const { markdown } = await convertPdfToMarkdown(filePath);
  return markdown; // Feeds clean GFM tables & math to context without vision tokens
}
